# 🗂️ Task manager

My own version of what I need/want in a task manager.

**[Try it live →](https://task-manager-22322.web.app)**

## Use locally

On localhost, Firebase is skipped and tasks are saved in your browser.

```bash
git clone https://github.com/Nathan-Celer/task-manager
cd task-manager
python3 -m http.server -d public
```

Then open http://localhost:8000 (not the `0.0.0.0` address the server prints).
